# media-src — file mentah (tidak di-commit)

- `photos/` → foto prewedding asli (JPG/PNG/HEIC). Jalankan `npm run media`.
- `video/`  → video prewedding asli (MP4/MOV). Jalankan `npm run media:video`, lalu `npm run media`.

Hasil yang sudah dikompres masuk ke `public/media/` (itulah yang di-commit & di-deploy).
